# أمريكان جروب — موقع صيانة الأجهزة المنزلية

موقع عربي RTL ثابت متعدد الصفحات، مصمم للرفع إلى GitHub Pages أو أي استضافة ملفات ثابتة. لا يحتاج إلى خادم أو قاعدة بيانات.

## الصفحات

- `index.html` — الرئيسية وطلب الصيانة السريع.
- `about.html` — من نحن.
- `services.html` — ست خدمات مع رسائل حجز خاصة بكل جهاز.
- `contact.html` — وسائل التواصل ونموذج واتساب.
- `privacy.html` — سياسة الخصوصية.
- `terms.html` — الشروط والأحكام.

## الرفع

ارفع محتويات هذا المجلد إلى جذر المستودع أو مجلد الموقع في استضافتك. اجعل `index.html` في جذر النشر. جميع روابط الصفحات نسبية. لا توجد خطوات بناء أو حزم مطلوبة.

## إعدادات التواصل التي يمكن تعديلها

- رقم واتساب المبرمج في `script.js`: `201069727678` (رقم مصري دولي دون علامة `+`، مشتق من الرقم المحلي `01069727678` الوارد في الطلب).
- أرقام الاتصال القابلة للنقر في ملفات HTML: `+20222591085` و`+20222591086`.
- العنوان والمواعيد النصية موجودة في تذييل الصفحات وصفحة التواصل.

النماذج تتحقق من الحقول في المتصفح ثم تفتح واتساب برسالة مشفرة للمراجعة. لا ترسل أو تخزن البيانات تلقائياً؛ على العميل الضغط على «إرسال» داخل واتساب. في الصفحة الرئيسية رابط واتساب لكل خدمة يحمل رسالة جاهزة مناسبة.

## ملاحظات قبل النشر

- يتضمن الموقع الشعار الأصلي المرفق باسم `american-united-group-logo.jpg` ويستخدمه في ترويسات وتذييلات الصفحات الست.
- فُسّرت ساعات «من ٩ ل ٥ ص» على أنها من ٩ صباحاً إلى ٥ مساءً. راجعها وأكد أيام العمل وموعدها.
- نصا الخصوصية والشروط مسودتان معلوماتيتان، وليسا رأياً قانونياً أو ضماناً تلقائياً للامتثال لقواعد الإعلانات أو القوانين. ينبغي مراجعتهما واعتمادهما مع مستشار محلي قبل الاستخدام التجاري.
- يستخدم الموقع خط Cairo من Google Fonts مع بدائل محلية. يظل الموقع قابلاً للاستخدام دون تحميل الخط الخارجي.
- عنوان خرائط Google رابط بحث للعنوان المكتوب؛ راجع الموقع الدقيق يدوياً قبل اعتماد الرابط.

## ميزات PWA

يتضمن `manifest.json` و`sw.js` وأيقونات مربعة مشتقة من شعار الشركة، مع نطاق ومسارات نسبية لدعم النشر داخل مسار مستودع GitHub Pages. صفحات الموقع تُخزّن للاستخدام بعد أول زيارة ناجحة؛ يحتاج التثبيت وتسجيل Service Worker إلى HTTPS (GitHub Pages يوفّره). يظهر شريط التثبيت على متصفحات Android الداعمة، بينما يعرض لمستخدمي iPhone تعليمات «مشاركة ثم إضافة إلى الشاشة الرئيسية».

تظهر على الشاشات الصغيرة قائمة سفلية بأزرار الرئيسية والخدمات والحجز والاتصال.
